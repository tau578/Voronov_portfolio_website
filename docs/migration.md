## Перенос

Самостоятельная статическая генерация на Node.js, без зависимостей и Framer runtime. Готовые HTML и CSS работают без клиентского JavaScript. Исходные медиа сохранены локально. Общий шаблон навигации и карточек; содержимое проектов отделено от вёрстки. Две настоящие HTML-страницы подходят для GitHub Pages, включая прямое открытие /projects/.

Сохраняются тёмный фон #080d12, панели #10171e, бирюзовые акценты, обводки, скругления и карточная сетка. На планшете — две колонки, на телефоне — одна. Исправлена невозможность карточек сжиматься; заголовки и email помещаются в узкий экран. Шрифт Inter (400, 700, 800) подключён локально; Arial используется как запасной.
